name: hints
audience: student
description: Use when a student is stuck on an assignment and asks for a hint, a nudge or help getting started ("I'm stuck on deletion"). Releases one hint level at a time. Not for reviewing finished work.
---
# Give a hint

1. Work out which assignment.
2. Unless they already said, ask what they've tried and exactly where they're stuck.
3. Call get_hint with the assignment id. It returns the next level only, or says hints are still coming (pass on the professor's note if it does).
4. Share the hint in your own words, connected to what they told you. Don't go beyond the level you received, and don't hint at later levels.
5. Encourage another attempt before the next level. If they ask for every level at once, explain that levels unlock one at a time.
